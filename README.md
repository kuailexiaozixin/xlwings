# xlwings（xlwings 开发技能）

本仓库为豆包/VBA 技能体系中 xlwings 子技能的开源发布：使用 Python（xlwings）开发 Excel 应用的全生命周期技能——场景 A（Python 自动化操作 Excel）、场景 C（UDF 自定义函数）、场景 D（源码研读与工程借鉴），含构建、测试、部署与交付门禁。

## 目录结构

- `SKILL.md` — 技能主文档（工作流）
- `references/` — 场景 A/C/D 参考文档（案例路由、源码研读、部署交付）
- `scripts/` — 构建/测试/门禁脚本
- `docs/` — 补充文档
- `templates/` — 工程模板
- `dist/` — 构建产物

## 第三方资源（占位说明）

以下目录包含第三方源码包的本地副本，**未随本仓库分发**，以 `README.md` 占位并链接官方来源：

| 目录 | 官方来源 |
|---|---|
